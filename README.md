# Counterweight — 웹 플레이 빌드

투석기 조립 2D 물리 퍼즐. 브라우저에서 바로 실행됩니다.

**플레이:** https://airwman-wq.github.io/stone-shot-web/

- 부품(투척 팔·무게추·회전축·슬링·해제 고리·탄환·매는 자리)을 조립해
  목표를 맞춥니다
- **조준하지 않습니다 — 조립이 곧 조준입니다**
- 탄환은 사람입니다. 발사되는 순간 래그돌이 되어 허우적대며 날아가고,
  세게 떨어지면 뼈가 부러집니다 (유혈 표현은 기본 꺼짐, 설정에서 켤 수 있음)
- 캠페인 12장 — 성 부수기, 성벽 너머 넘기기, 깃발 잡기, 보초·왕 맞히기
- 들판에 구경꾼이 서 있습니다. 사람을 짧게 던지면 볼링핀처럼 쓰러집니다
- 던진 사람이 어떻게 됐는지가 결과 화면에 남습니다 (뼈 몇 대, 몇 명 넘어뜨렸는지)
- **대결** — 두 공성기가 마주 보고 번갈아 던집니다. 바퀴로 조금씩 움직이고,
  바람이 불고, 맞은 자리에 따라 뼈대·무게추·팔이 부서집니다
- 첫 로딩에 10~20초 걸립니다 (wasm 약 42MB)
